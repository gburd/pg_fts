Schema / index setup:
  CREATE EXTENSION vchord_bm25 CASCADE;
  ALTER TABLE docs ADD COLUMN tv tsvector;
  UPDATE docs SET tv = to_tsvector('english', coalesce(title,'')||' '||coalesce(body,''));
  VACUUM docs;
  CREATE INDEX docs_vc ON docs USING bm25(tv bm25_ops);
  VACUUM (FREEZE, ANALYZE) docs;

Exact ranked query form (verified against /nvme/vchord/tests/sqllogictest/*.slt):
  SET "bm25.limit" = <k>;   -- must be >= LIMIT k, controls how many candidates the bm25 index AM returns
  SELECT id FROM docs
  ORDER BY tv <&> to_bm25query(to_tsvector('english', '<term>'), 'docs_vc')
  LIMIT <k>;

  Note: to_bm25query signature is to_bm25query(tsvector, regclass) -- i.e. (query_tsvector, index_name),
  NOT (index, query_str). The <&> operator computes a *negative* bm25 score (ORDER BY ascending = most relevant first).
