Build notes
-----------
- openblas-devel was required (pgvector/pg_search release link needs -lopenblas), installed via dnf.
- Root EBS volume is only 8G and filled up during `cargo pgrx install --release`
  (winapi-0.3.9 unpack failed, "No space left on device"). Fix: moved
  ~/.cargo/registry and ~/.rustup to /nvme and symlinked back into $HOME
  before retrying the release build. Build then completed cleanly.
- shared_preload_libraries = 'pg_search' set in postgresql.conf, cluster
  restarted with `pg_ctl -D /nvme/pgdata -w restart`, BEFORE CREATE EXTENSION.
- pg_search requires the vector extension: `CREATE EXTENSION vector;` then
  `CREATE EXTENSION pg_search;` (extname/extversion confirmed: vector 0.8.5,
  pg_search 0.25.6).

Exact commands used
--------------------
Load:
  psql -h /tmp -d bench -qc "CREATE TABLE docs (id bigint, title text, body text)"
  psql -h /tmp -d bench -qc "\copy docs FROM '/nvme/w.tsv' WITH (FORMAT csv, DELIMITER E'\t', QUOTE E'\b')"
  -> row count confirmed: 2188038

Build (pgvector then pg_search):
  cd /nvme/pgvector && make PG_CONFIG=/nvme/pg17/bin/pg_config && make install PG_CONFIG=/nvme/pg17/bin/pg_config
  cargo install --locked cargo-pgrx@0.19.2
  cargo pgrx init --pg17 /nvme/pg17/bin/pg_config
  cd /nvme/paradedb/pg_search && cargo pgrx install --release --pg-config /nvme/pg17/bin/pg_config

Extension + index:
  CREATE EXTENSION vector;
  CREATE EXTENSION pg_search;
  CREATE INDEX docs_ps ON docs USING bm25(id, body) WITH (key_field='id');
  VACUUM (FREEZE, ANALYZE) docs;

Query forms used for timing:
  ranked:  SELECT id FROM docs WHERE body @@@ '<term>' ORDER BY paradedb.score(id) DESC LIMIT k;
  count:   SELECT count(*) FROM docs WHERE body @@@ 'year';
  AND:     SELECT id FROM docs WHERE body @@@ 'slovakia AND hungary' ORDER BY paradedb.score(id) DESC LIMIT 10;
  phrase:  SELECT id FROM docs WHERE body ### 'united states' ORDER BY paradedb.score(id) DESC LIMIT 10;
           (pg_search's `###` phrase operator; plain @@@ 'text' does not accept quoted phrases)
  prefix:  SELECT id FROM docs WHERE body @@@ pdb.parse('body:hung*') ORDER BY paradedb.score(id) DESC LIMIT 10;
           (Tantivy wildcard via pdb.parse() query-string syntax, field-qualified 'body:hung*')
